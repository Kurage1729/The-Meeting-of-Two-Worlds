# Editing and Navigation Guide

This package is organized as a Markdown-first GitHub Pages wiki. `index.md` is the main page.

## Directories

| Directory | Purpose |
|---|---|
| `countries/` | Modern country articles |
| `regions/` | Regional overview and navigation pages |
| `polities/` | Historical kingdoms, Crowned States, and autonomous governments |
| `history/` | Wars, revolutions, incidents, and long-term historical processes |
| `culture/` | Languages, writing systems, religions, and social customs |
| `people/` | Biographical and ruler-list articles |
| `maps/` | Map index and future map files |

## Linking convention

All internal links are relative and include the `.md` extension. Examples:

```markdown
[Mexica](countries/mexica.md)
[Main page](index.md)
[Spanish conquest of the Mexica Empire](history/mexica-conquest.md)
```

Articles inside a directory add `../` when linking back to the project root.

## Article convention

Each article begins with:

1. an H1 page title;
2. a breadcrumb line;
3. a short summary or infobox;
4. topic sections;
5. a `Related articles` section.

Short or incomplete subjects remain grouped in overview articles. They can be split into separate files when they gain several sections or are linked frequently from other pages.
