# TMTW Drafts

このフォルダは、日本語で設定を検討するための場所です。

ここに書かれた内容は、確定設定ではありません。`context/all-context.md`の自動生成対象からも除外されます。結論が出たら、対応する英語のWikiページへ内容を反映してください。

## 基本的な使い方

1. `TEMPLATE.md`をコピーして、話題ごとのDraftを作る。
2. 日本語で案・疑問・史実考証上の問題を書く。
3. GPTに`context/all-context.md`とDraftのリンクを渡して相談する。
4. 結論が出たら、GPTに更新対象の英語Wikiページを作らせる。
5. 英語Wikiを更新した後、DraftのStatusを`Resolved`にする。

## Status

- `Draft` — 検討中。
- `Review` — ほぼ決定したが、整合性確認が必要。
- `Resolved` — Wikiへ反映済み。
- `Rejected` — 不採用だが、議論の記録として残す。

## ファイル名

ファイル名には半角英数字とハイフンを使います。

```text
mexica-independence.md
vinlandic-sound-changes.md
maya-religion.md
```
